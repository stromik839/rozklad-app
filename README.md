# Розклад — Android-приложение

Звонки и уроки на каждый день, структура учебного года, питание, эвакуация,
дежурства и виджеты на рабочий стол. Интерфейс на украинском.

**Расписание составляют прямо в приложении и делятся им ссылкой, кодом,
QR-кодом или файлом** — с одноклассниками, друзьями, всем классом. Подходит
любой школе: сервер не нужен, всё хранится на телефоне. Время берётся из
телефона, фото для обоев — через системный выбор фото. Единственные
разрешения — точные будильники для виджетов (выдаются автоматически при
установке, без вопросов).

## Как это работает

**Составить** (первый запуск → «Скласти розклад», потом шестерёнка → «Розклад» → «Змінити»):

- звонки, классы и уроки на каждый день (подсказки названий предметов);
- семестры и каникулы — для нового расписания уже подставлены даты 2026–2027;
- «Харчування, евакуація, чергування» — необязательно. Классы в строке пишутся
  через запятую («7-А, 7-Б») или промежутком («10–11») — строка своего класса
  подсвечивается сама.

Классов может и не быть: тогда это просто звонки и перемены — приложение
считает каждый звонок уроком и показывает, что сейчас и что дальше (виджеты тоже).

**Поделиться** (шестерёнка → «Розклад» → «Поділитися»; после сохранения нового
расписания открывается само). Галочками выбирается, чем делиться:

| Часть | Что внутри |
|---|---|
| Уроки | классы и уроки на неделю |
| Дзвінки й перерви | время уроков и перемен |
| Навчальний рік | семестры и каникулы |
| Харчування, Евакуація, Чергування | соответствующие таблицы |
| Оформлення | тема, цвета, скругление углов, вид обоев, стиль виджетов |
| Шпалери | само фото обоев — **только файлом** |

Можно всё сразу или по частям: например, только звонки. Если классов несколько,
можно отдать все или один («Для якого класу») — QR одного класса заметно проще
сканировать. Дальше: QR-код, «Надіслати посилання» (Telegram, Viber…),
«Копіювати посилання», «Копіювати код», «Надіслати файлом».

Фото обоев в QR-код и ссылку не помещается (это сотни килобайт), поэтому
обои передаёт только файл: «Надіслати файлом» отправляет `.json` через
системное «Поділитися», в нём может быть и всё остальное.

**Получить:**

- навести камеру на QR-код или открыть ссылку → страница «Розклад» →
  «Відкрити в застосунку» (если приложения нет — «Завантажити застосунок»);
- нажать на присланный файл в Telegram / файловом менеджере → открыть с помощью
  «Розклад» (или «Поділитися» → «Розклад»);
- или в приложении: «Отримати: посилання, код або файл» → вставить ссылку или код,
  либо «Відкрити файл».

Приложение покажет, что внутри, и отметит, что заменить. Заменяется только
отмеченное, остальное остаётся своим: можно взять уроки у одного человека, а
звонки поставить свои или от другой школы. Если уроков в какой-то день больше,
чем звонков, приложение предупредит (лишние уроки сохраняются и появятся, когда
добавите звонки). Если пришли уроки без звонков, а своих звонков ещё не было,
подставляются обычные из заготовки — с подсказкой их проверить. Оформление и
обои, пришедшие вместе с расписанием, по умолчанию не отмечены — свою тему никто
не меняет случайно.

Если в расписании несколько классов, приложение спросит, какой свой. Когда тем
же расписанием поделились снова после изменений, приложение напишет
«Це новіша версія ваших уроків» (или предупредит, что версия старее).

Кто пользовался приложением до этой версии, после обновления получает
встроенное расписание как своё: класс, обои и виджеты остаются.

## Один раз: включить страницу для ссылок (GitHub Pages)

Ссылки и QR-коды ведут на `https://stromik839.github.io/rozklad-app/` — это
папка `docs` в репозитории. Пока её не включить, ссылка откроет ошибку 404.

Сначала залейте версию, в которой есть папка `docs` (см. «Пришёл новый архив»),
потом включите страницу. На сайте: репозиторий → **Settings** → **Pages** →
**Source: Deploy from a branch** → ветка **master** (у этого репозитория основная
ветка — `master`), папка **/docs** → **Save**. Через минуту-две страница
заработает. Или в Termux одной командой (ветку подставит сама):

```bash
cd ~/Rozklad-android && gh api -X POST repos/stromik839/rozklad-app/pages -f "source[branch]=$(git branch --show-current)" -f "source[path]=/docs"
```

Ответ `The main branch must exist` значит, что в команде указана не та ветка;
ошибка про `/docs` — что папка `docs` ещё не залита.

Проверить: открыть `https://stromik839.github.io/rozklad-app/` — должна
появиться страница «Розклад» с кнопкой «Завантажити застосунок» (она качает
последний `Rozklad.apk` из **Releases**).

- Страница **бесплатна только для открытого (public) репозитория**. Если сделать
  его приватным, ссылки и QR перестанут открываться — останутся коды и файлы
  («Отримати: посилання, код або файл»).
- Переименуете репозиторий — поменяйте адрес в двух местах:
  `app/src/main/assets/app.js` (`shareBase`) и `app/src/main/AndroidManifest.xml`
  (`android:host` / `android:pathPrefix`). Сама страница адрес берёт сама.
- Код расписания — после `#` в ссылке: браузер никуда его не отправляет.

## Что где лежит

- `app/src/main/assets/index.html` — весь экран приложения: расписание,
  настройки, редактор, «Поділитися», «Отримати».
- `app/src/main/assets/app.js` — автор приложения и адрес страницы для ссылок.
- `app/src/main/assets/data.js` — **встроенное расписание, теперь только
  заготовка**: из него берутся звонки, семестры и каникулы для нового расписания,
  и его получают как своё те, кто обновился со старой версии. Правки в нём
  **не попадают** на телефоны, где расписание уже есть, — для этого редактор
  в приложении и «Поділитися».
- `app/src/main/assets/qr.js` — QR-коды (свой код, без библиотек).
- `app/src/main/assets/code.js` — коды расписания для проверки в браузере
  (в приложении их делает `ShareCode.java`).
- `app/src/main/java/.../ShareProvider.java` — отдаёт файл, которым делятся,
  только для чтения и только тому, кому его отправили.
- `docs/` — страница для ссылок (GitHub Pages).

## Владелец и логотип

Логотип показывается **только в настройках**, в блоке «Про застосунок», рядом с
названием канала; нажатие открывает Telegram-канал. На белой теме — красный
квадрат с белым знаком, на чёрной — белый с красным; углы скругляются вместе со
всем интерфейсом («Вигляд» → «Заокруглення кутів»: 0 % — квадрат, 100 % — круг).

Иконка приложения на рабочем столе — прежняя (таблица с зелёной строкой). Она же
на экране приветствия и на странице для ссылок.

Название и ссылка — в `app/src/main/assets/app.js`:

```js
"author": {
  "name": "𝗞𝗿𝘆𝘀𝗺𝗲𝗱 𝗱𝗲𝘃𝗲𝗹𝗼𝗽𝗲𝗿",
  "telegram": "https://t.me/+Awp124F8mthjNDIy"
},
```

`telegram` понимает имя (`@имя`), ссылку `t.me/имя` и приглашение в канал
(`https://t.me/+…`). Под названием пишется «Telegram-канал» (для приглашения)
или «Telegram: @имя», ниже — версия приложения.

## Что на экране

Сверху звонки и уроки на сегодня. Ниже, если листать: структура учебного года
с отсчётом до каникул, график питания, план эвакуации и дежурства — строки
своего класса выделены, над каждой таблицей коротко написано главное для класса.
Незаполненные разделы не показываются.

## Настройки (шестерёнка)

- **Розклад** — название и дата обновления; «Поділитися», «Змінити»,
  «Отримати: посилання, код або файл».
- **Клас** — свой класс (если в расписании есть классы).
- **Тема** — как в системе / белая / чёрная.
- **Шпалери** — фото из галереи; «Налаштувати» — сдвинуть и увеличить фото
  пальцами. Ползунки: затемнение, прозрачность и размытие под таблицами.
- **Вигляд** — закругление углов (логотип тоже).
- **Кольори** — отдельно для белой и чёрной темы: фон, текст, рамки,
  подсветка «зараз» и «далі». 20 готовых цветов + «Інший колір», есть сброс.
- **Віджети** — у каждого виджета свои настройки (см. ниже).
- **Про застосунок** — логотип и Telegram-канал владельца, версия.

## Виджеты

В списке виджетов на рабочем столе есть три: «Розклад: дзвінки», «Розклад:
уроки» и «Розклад: уроки й дзвінки». Их же можно добавить из приложения:
шестерёнка → «Налаштувати віджети» → «Додати на робочий стіл» (если рабочий
стол это не поддерживает, приложение подскажет, как добавить вручную).

У каждого виджета свои настройки: что показывать, своя тема (не зависит от
темы приложения), фон (по умолчанию без фона; цвет на выбор или фото — своё
или обои приложения), прозрачность, размытие, затемнение, углы, размер текста.
«Застосувати цей стиль до всіх віджетів» копирует оформление на остальные.
Полученное «Оформлення» применяет стиль виджетов ко всем виджетам и к новым
(что показывать и свои фото виджетов остаются).

Виджет перерисовывается в момент каждого звонка (в учебные дни), в полночь, при
смене времени на телефоне и сразу после того, как расписание получили или
изменили. Пока расписания нет, виджет просит открыть приложение. Если на
Xiaomi/HyperOS виджет обновляется с опозданием, включите приложению
«Автозапуск» в его настройках.

## Пришёл новый архив с изменениями

В Termux (архив в «Загрузках», имя подставь своё):

```bash
cd ~ && unzip -o /storage/emulated/0/Download/Rozklad-v9.zip && cd ~/Rozklad-android && git add -A && git commit -m "Оновлення" && git push
sleep 15 && gh run watch
gh release download -p Rozklad.apk -D /storage/emulated/0/Download --clobber && termux-open /storage/emulated/0/Download/Rozklad.apk
```

`unzip: cannot find or open` — архива с таким именем в «Загрузках» нет: его не
скачали или телефон сохранил под другим именем (например, `… (1).zip`). Найти:
`ls -t /storage/emulated/0/Download | head`.

Новая версия встаёт поверх старой, настройки и обои сохраняются.

## Если сборка упала

- В Termux: `gh run view --log-failed` — в конце будет сообщение.
- На сайте: **Actions** → красный запуск → упавший шаг.

Шаг **Check schedule (data.js)** проверяет встроенную заготовку: если там
ошибка, сообщение подскажет строку.

## Свой ключ подписи

Каждый APK подписан ключом, и телефон ставит обновление поверх старой версии,
только если ключ совпадает. Сейчас ключ (`app/rozklad.p12`) лежит в открытом
репозитории, поэтому кто угодно может собрать APK, который встанет поверх
нашего. Свой ключ хранится только у тебя и в зашифрованных секретах GitHub.

Один раз в Termux:

```bash
pkg install -y openjdk-17
keytool -genkeypair -keystore ~/rozklad-release.p12 -storetype PKCS12 -alias rozklad -keyalg RSA -keysize 4096 -validity 20000 -dname "CN=Rozklad"
```

keytool дважды попросит придумать пароль (не короче 6 символов). Потом:

```bash
base64 -w0 ~/rozklad-release.p12 | gh secret set ROZKLAD_KEYSTORE_B64 -R stromik839/rozklad-app
gh secret set ROZKLAD_KEYSTORE_PASSWORD -R stromik839/rozklad-app
cp ~/rozklad-release.p12 /storage/emulated/0/Download/
```

Вторая команда попросит вставить тот же пароль.

- **Сохрани ключ и пароль.** Отправь файл `rozklad-release.p12` себе в
  «Избранное» Telegram, пароль запиши отдельно. Без ключа обновления снова
  перестанут ставиться поверх.
- Следующая сборка подпишется новым ключом: в журнале шага **Signing key**
  будет «Підпис: власний секретний ключ».
- **Один раз** на каждом телефоне нужно удалить старый «Розклад» и поставить
  новый: класс, обои и виджеты придётся настроить заново, а расписание —
  получить ещё раз (ссылкой, QR или файлом). Совет: перед удалением
  «Поділитися» → «Надіслати файлом» со всеми галочками (и обоями) себе в
  «Избранное» — потом откроете этот файл в новом приложении, отметите всё, и
  вернутся расписание, оформление, обои и стиль виджетов (сами виджеты
  добавить заново). Дальше обновления снова ставятся поверх.
- После перехода старый `app/rozklad.p12` больше не нужен, его можно удалить.

Полностью запретить перепаковать APK не может ни одно приложение. Свой ключ
гарантирует, что подделку нельзя поставить как обновление вашего приложения,
а автор в настройках показывает, чьё оно.

## Первый раз: залить на GitHub (Arch)

```bash
sudo pacman -S --needed git github-cli
gh auth login                      # один раз: GitHub.com → HTTPS → Login with a web browser
cd ~/Downloads && unzip Rozklad-android.zip && cd Rozklad-android
git init && git add . && git commit -m "Розклад"
gh repo create rozklad-app --public --source=. --push
```

Если git спросит «Please tell me who you are»:
```bash
git config --global user.name "Имя"
git config --global user.email "почта@example.com"
```

## Мелочи

- Время 8-го урока (14:55–15:40) во встроенной заготовке на листке не указано —
  поставлено по аналогии.
- Проверить страницу в браузере на любую дату со встроенным расписанием:
  `index.html?demo&now=2026-09-30T10:42&cls=7-А`. Проверить получение
  расписания: `index.html#КОД`.
- Шрифт `fonts/RozkladSerif-Bold.ttf` — Liberation Serif Bold (аналог Times New
  Roman), в котором оставлены только латиница, кириллица и знаки препинания. По
  лицензии SIL OFL 1.1 изменённая версия не может называться «Liberation»,
  поэтому он переименован в «Rozklad Serif». Лицензия —
  `app/src/main/assets/fonts/LICENSE-LiberationSerif.txt` (копия лежит и в
  `docs/fonts` — страница ссылок использует тот же шрифт).
